# 插件市场

插件以源码包形式交付：免费插件直接安装，专业插件按插件、客户与有效期签发离线授权。

**浏览、搜索、下载与安装统一在官网插件市场：**

<!-- __market__ 由 .vitepress/config.mts 的 MARKET_URL 注入；独立域名部署时设置该环境变量。 -->
- [打开官网插件市场 →](__market__)

官网市场与后台「系统管理 → 插件管理 → 插件市场」读同一份 `config/plugin-market.yaml`：

- 按名称 / 能力搜索，按分类、免费 / 专业筛选
- 详情页提供后台一键安装、CLI 安装命令、源码包下载与 SHA-256 校验
- 机器可读目录：`/plugins/index.json`

价格以购买时的报价为准；授权与购买方式见[购买授权](/buy)。
