# 更新日志

## 0.1.0（初始版本，尚未正式发布）

框架清单里的 `framework_version` 为 `0.1.0`。下面只列代码中已经存在的能力，不代表已在真实数据库、浏览器或多实例环境中完整验证。

**框架**

- 多租户（共享库加 `tenant_id`），租户额度（用户数、角色数、存储）与到期控制。
- RBAC 权限；MySQL、MariaDB、PostgreSQL 各有一份迁移 SQL。
- 登录：账号密码、手机号短信，以及企业微信、钉钉、飞书、Google、GitHub、通用 OIDC 的第三方登录。
- 内置 OIDC 提供方（SSO）。
- 开放平台：个人访问令牌、应用签名调用、Webhook，以及运行时生成的接口文档。
- 文件：断点续传上传，本地或 S3 兼容存储；异步导出中心；数据库备份。
- 通知：站内、邮件、短信、群机器人。
- 公告、站内消息、工作台卡片（可隐藏与排序，插件也能提供卡片）。
- 监控：服务、缓存、接口、健康检查、前端错误上报。
- 国际化（简体中文、英文，可增加语言）、PWA。

**插件与工具**

- 源码插件体系，离线签名授权，支持授权域名绑定、到期自动下线与离线吊销清单。
- 命令行 `nexadmin`：插件管理与授权签发（`plugin`）、新建项目（`new`）、生成业务模块（`add module`）、语言包（`i18n`）、升级（`upgrade`）、发布检查与打包（`release check`、`release pack`）。
- 官方插件：定时任务（含工作台概览卡片）、数据变更审计、代码生成器。

**尚未验证**

- 三种数据库的迁移与种子、初始化向导、多实例部署，没有在真实环境中完整跑通。
- 授权查询页没有用真实授权文件验过签。
