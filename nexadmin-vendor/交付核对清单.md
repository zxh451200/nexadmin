## CLI 与打包约定

命令在框架根目录运行，`nexadmin` 可替换为 `go run ./cmd/nexadmin`。可选参数记法仅用于说明，执行时不要输入方括号。

```bash
go run ./cmd/nexadmin plugin list
go run ./cmd/nexadmin plugin pack cron
# 安装：plugin pack 产出的 zip 或目录
# 覆盖安装：flag 必须在位置参数前
go run ./cmd/nexadmin plugin install --force cron-1.0.0.zip
go run ./cmd/nexadmin i18n check --all
go run ./cmd/nexadmin upgrade --from ../nexadmin-0.1.1.zip --to 0.1.1 --dry-run
go run ./cmd/nexadmin release check --strict
```

`plugin install --force` 会覆盖已安装文件并跳过框架版本限制，使用前应保存本地定制。`plugin list` 只扫描磁盘清单与离线授权，不证明 Go 包已编入或管理器已挂载，须结合运行时 `/api/v1/plugins` 和启动结果核对。

发行包用 `plugin pack [--out <路径.zip>] <id>` 从已安装插件直接生成（`--out` 须在位置参数之前）；独立源码包目录已于 2026-10-25 整合进仓库后移除，内容可再生。`release pack` 是框架打包，默认排除已装插件；已有插件或开发公钥等 FAIL 会阻止正常打包，不用 `--force` 规避正式交付检查。`i18n add --translate` 已实现，使用环境变量配置 OpenAI 兼容模型；`i18n check` 缺 key 只提示并返回 0，不是发布闸。框架插件开发指南已同步到文档站副本（保留来源注释）。
