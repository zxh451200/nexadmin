# 第三方开源组件说明

本仓库在框架自带依赖之外引入的第三方 UI/素材组件。引入即带上游许可文本的出处链接；升级依赖时请同步核对本页。

## 登录滑块验证码（core/auth、web 登录页）

| 组件 | 许可 | 来源 | 用途 |
| --- | --- | --- | --- |
| [go-captcha v2](https://github.com/wenlng/go-captcha) | Apache-2.0 | Go 模块 `github.com/wenlng/go-captcha/v2` | 滑块拼图渲染：真实照片背景 + 带阴影/蒙版的拼图形状（`core/auth/slider_render_photo.go`） |
| [go-captcha-assets v1.0.7](https://github.com/wenlng/go-captcha-assets) | Apache-2.0 | Go 模块 `github.com/wenlng/go-captcha-assets` | 内嵌素材：8 张实拍背景与 4 组拼图形状（只引入子集控制二进制体积） |
| [rc-slider-captcha v1.9](https://github.com/caijf/rc-slider-captcha) | MIT | npm `rc-slider-captcha` | 登录页滑块拖拽交互组件（`web/src/framework/pages/login/CaptchaField.tsx`） |

引入位置与契约：

- Go 侧 `renderSliderPhoto` 与手绘版 `renderSlider` 同签名同契约（背景/抠块 dataURI、孔位 X 只留服务端）；素材初始化失败自动回退手绘版。
- 前端 `rc-slider-captcha` 只负责拖拽交互与动画；校验仍走自有接口 `/auth/slider/verify`（x 容差 + 轨迹行为校验）。
- go-captcha 为 Apache-2.0：上游 LICENSE 随模块分发（Go module cache 内 `go-captcha@v2.0.5/LICENSE`、`go-captcha-assets@v1.0.7/LICENSE`），本页即归属声明。
