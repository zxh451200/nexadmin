## 口径约定

- 这里写的是**系统实际行为**，不是设计意图；和代码不一致时以代码为准，并当作 bug 提。
- 参数的含义与默认值以[配置参考](配置参考.md)为准，部署步骤以[部署与运维指南](部署与运维指南.md)为准，本文不重复。
- 权限码一律写成 `模块:动作`（如 `ticket:edit`）；数据范围（本人 / 本部门 / 全部等）在[开放平台与权限](features-access.md)里讲。
- 涉及"必须真库才能验"的链路（迁移、登录、回调），本文只给判定口径，手工复跑配方不进对外文档。
