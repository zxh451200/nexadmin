# 媒体能力接入

本文说明 NexAdmin 的图片、视频与地图能力：哪些在框架内、哪些在插件里，运维怎么开、开发怎么用、出错怎么查。

## 1. 能力与归属

| 能力 | 位置 | 是否默认开启 | 依赖 |
| --- | --- | --- | --- |
| 图片生成 WebP 副本（原图保留、按 `Accept` 下发） | 框架（文件模块 + 上传组件） | **关**，系统设置里打开 | 无 |
| 存量图片批量补 WebP | 插件 `media` → 媒体优化 → 图片 | — | 浏览器 + `file:upload` 权限 |
| 视频托管（Cloudflare Stream / Bunny 直传） | 插件 `media` → 媒体优化 → 视频 | 关 | 厂商账号与 Key |
| 视频登记（阿里云 / 腾讯云 / 已有资产） | 同上 | 关 | 播放域名 |
| 正文嵌入视频（B 站 / YouTube / Cloudflare Stream） | 框架（富文本 + 两侧 HTML 过滤白名单） | 开 | 无 |
| 地图选点与逆地理 | 框架 `framework/map` + 插件 `maps` | 关 | 地图厂商 Key |

`media` 与 `maps` 是 **pro 插件**：需要导入 license 才会挂载路由、建表并显示菜单。

## 2. 安装与授权

1. 把插件放进 `plugins/`（源码插件随框架编译），或按发行包安装；确认 `plugins/plugins.go` 里有对应导入。
2. 在「插件管理」导入 license。未授权时 `/api/v1/plugins/media/*` 会落到"插件未启用"兜底路由，`plg_media_*`、`plg_maps_setting` 也不会建表。
3. 重启服务：迁移与菜单补种在启动时执行（菜单只补不改，已有菜单不会被覆盖）。
4. 角色里勾选权限点：

| 权限码 | 用途 |
| --- | --- |
| `media:optimize` | 媒体优化页与全部接口（图片统计/待处理、视频配置/上传/台账） |
| `file:upload` | 图片补 WebP 时上传副本（走文件模块的 tus） |
| `map:config` | 地图服务配置页与逆地理代理 |

## 3. 图片

### 3.1 开启与行为

系统设置 → 上传限制 → 打开「为图片生成 WebP 副本」。

- **原图永远保留**：额外上传一份 WebP 副本（浏览器端转码，最长边 2560、质量 0.82）。
- 副本比原图大时直接丢弃；GIF / SVG / 已是 WebP / AVIF 的跳过。
- 下发方式：URL 不变，`/files/:id/content` 按 `Accept: image/webp` 选副本，并带 `Vary: Accept`；老浏览器拿原图。
- 副本是隐藏的派生行：不进文件列表、不计分组数量、算存储用量、随原文件删除、可见性永远继承原图。

### 3.2 存量批量

媒体优化 → 图片 → 「生成全部」。

- 转码在**管理员浏览器**里完成：逐张拉原图 → 转 WebP → 上传副本。页面不要关，建议一次跑一页（20 张）。
- 只处理「公开、已落盘、JPEG/PNG、还没有副本」的图；私有图片与 GIF/SVG 不在列表里。
- 失败的行保持原状，可重试；「本次节省」是这一轮省下的字节数。

### 3.3 开发接入

- 图片：不需要改代码，走框架上传组件的上传都会自动生效。
- 自定义上传：`uploadToTus(file, endpoint, { kind: 'image', variantOf: 原图 id })`。
- 取图：`<img src="/api/v1/files/{id}/content">` 或公开链接；浏览器会自动协商 WebP。

## 4. 视频

### 4.1 厂商矩阵

| 厂商 | 直传 | 播放地址 | 配置字段 |
| --- | --- | --- | --- |
| Cloudflare Stream | 是（tus） | `customer-<子域>.cloudflarestream.com/<uid>/iframe` | Account ID / API Token / 播放子域 |
| Bunny Stream | 是（tus + 签名） | `<pull zone>.b-cdn.net/<guid>/playlist.m3u8` | Library ID / API Key / Pull Zone |
| 阿里云 VOD | 否，只登记 | `<播放域名>/<videoId>/index.m3u8` | 播放域名 |
| 腾讯云 VOD | 否，只登记 | `<播放域名>/<fileId>.m3u8` | 播放域名 |

浏览器**直传厂商**，服务端只负责签名与台账：视频不经过本站存储，本站不转码。播放/下载地址由服务端按 `videoId` 推导，不信任客户端传入的 URL。

### 4.2 操作

1. 媒体优化 → 视频 → 启用 → 选厂商 → 填字段 → 保存。
2. 能直传的厂商点「上传视频」；四家都能点「登记已有视频」（粘贴 videoId / fileId 与显示名）。
3. 台账里可「复制 MP4 直链」（仅 CF / Bunny）或打开播放弹窗。
4. 把视频放进正文：编辑器「插入视频」→ 粘贴 MP4 直链，或 B 站 / YouTube / Cloudflare Stream 的嵌入地址。

### 4.3 前置条件与计费

- Cloudflare：账号需开启「允许 MP4 下载」，否则直链 404；按存储分钟数与播放分钟数计费。
- Bunny：库设置需开启 MP4 Fallback；按存储与流量计费，有试用期。
- 阿里云 / 腾讯云：转码与加速流量单独计费（阿里云存储 50G 以内免费）；播放域名需备案，或用厂商测试域名。

## 5. 正文嵌入

`<iframe>` 只允许以下来源，其它 iframe 连同内容整块丢弃（前后端同一份白名单）：

- `https://www.youtube.com/embed/*`、`https://www.youtube-nocookie.com/embed/*`
- `https://player.bilibili.com/player.html`
- `https://customer-*.cloudflarestream.com/<uid>/iframe`

编辑器粘贴 B 站视频页、`watch?v=`、`youtu.be` 短链或 CF 播放器地址会自动规范化。`http://`、任意站外域名、`javascript:`、`srcdoc` 一律拒绝。该白名单在 Go 侧，改完需重新构建二进制。

## 6. 地图

1. 安装并激活 `maps` 插件 → 系统 → 地图服务，按厂商分别启用并填 Key：
   - 高德：JS API Key（Web 端，下发浏览器）+ Web 服务 Key（仅后端，用于逆地理）
   - 百度：浏览器端 AK + 服务端 AK（服务端 AK 需开通「逆地理编码」）
   - 谷歌：API Key（需启用 Maps JavaScript API 与 Geocoding API）
2. 开发用法：

```tsx
import { LocationField, gcj02ToWgs84, type GeoPoint } from '@/framework/map'

const [point, setPoint] = useState<GeoPoint | null>(null)
<LocationField value={point} onChange={setPoint} label="门店位置" />
```

- 未安装插件时退化为手填经纬度，不影响表单提交。
- 坐标系随厂商：高德 GCJ-02、百度 BD-09、谷歌 WGS-84；入库前用 `gcj02ToWgs84` / `bd09ToGcj02` 统一。
- 逆地理编码走后端代理，服务端 Key 不会下发浏览器。

## 7. 排障

| 现象 | 原因与处理 |
| --- | --- |
| 高德逆地理报 `USERKEY_PLAT_NOMATCH` | 用了 JS API Key 调 Web 服务接口，需另建「Web 服务」Key |
| 百度报 `240 APP 服务被禁用` | 该 AK 未开通「逆地理编码」，或 AK 类型是浏览器端；控制台勾选服务或改用服务端 AK |
| 上传后正文直链 404 | CF 未开启「允许 MP4 下载」/ Bunny 未开 MP4 Fallback / 阿里腾讯未转码 |
| 正文里的 iframe 被丢弃 | 域名不在白名单；确认是 `https` 且路径为 `/embed/`、`/player.html` 或 `/<uid>/iframe` |
| 媒体优化页为空 | 没有「公开 + JPEG/PNG + 无副本」的图片，或插件未授权 |
| 「生成全部」中途停下 | 页面被关闭或网络中断；重新打开继续即可，已完成的不会重复转 |

## 8. 上线检查清单

1. `media` / `maps` license 已导入，菜单出现，迁移已建表。
2. 图片开关按需打开；先跑一页批量确认效果，再全量。
3. 视频厂商 Key 已验证：能拿到上传地址、能播放、能复制直链。
4. 角色权限：`media:optimize`、`file:upload`、`map:config` 已按岗分配。
5. 重新构建二进制（iframe 白名单与 htmlsafe 在 Go 侧）。
6. 对外说明已知限制：阿里/腾讯暂不支持直传；图片批量需要管理员在浏览器里跑；视频转码由外部托管完成。
