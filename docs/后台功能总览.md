# 后台功能总览

这份文档带你把后台的每个页面过一遍：每个页面是干什么的、平时怎么用。读完就能对着后台自己上手，不需要任何开发背景。

> 想先动手装环境？看[快速开始](quickstart.md)。想知道每个接口和权限点的精确口径？看[功能与权限清单](features.md)。

## 按角色找功能

| 你想做的事 | 去哪里 |
| --- | --- |
| 加个同事的账号、给他分权限 | 系统管理 → 用户管理、角色管理 |
| 看系统跑得正不正常 | 系统监控 |
| 发个通知 / 管理文件 | 内容管理 |
| 处理客户的咨询和问题 | 业务中心 → 在线客服、工单中心 |
| 配置审批流程 | 业务中心 → 审批中心 |
| 收钱、退款、对账 | 业务中心 → 支付中台 |
| 改官网内容 | 网站管理 |
| 装插件、做二次开发 | 开发与安全 |

## 工作台

登录后第一屏。统计卡片（今日登录、未读消息、用户总数、存储用量等）、近 7 天趋势图、待办事项、快捷入口和最近公告都在这里。

- 点右上角「编辑布局」可以拖动、隐藏每张卡片，布局按用户各自保存。
- 统计只统计本租户的数据。

## 导入导出

- **导出中心**：所有「异步导出」的任务列表（比如用户列表的 xlsx 导出）。能下载结果、取消、重试、删除。普通用户只能看到自己的任务，管理员能看到全租户的。
- **导入中心**：统一的 Excel / CSV 导入入口。先下载模板，填好后上传，系统会校验表头和必填项，出错的行单独报告，不会影响正确的数据。哪些业务表能导入，由各业务模块自行注册。

## 系统管理

- **用户管理**：同事的账号都在这里。新建/编辑/删除（支持批量）、启用停用、重置密码、解锁、分配角色/部门/岗位，也支持 Excel 导入和导出。谁忘了密码，管理员在这里重置。
- **角色管理**：权限是按角色发的。新建一个角色，勾上它能看到哪些菜单、能用哪些按钮，再设置数据范围（只能看自己的 / 本部门 / 全部等），然后把角色分给用户。
- **菜单管理**：后台左侧菜单树。可以增删菜单、改图标和排序、控制显示隐藏；按钮级权限也在这里登记。改的是全站菜单（平台级）。
- **部门管理**：公司的组织架构树，支持多级和拖拽排序；「岗位」页签维护岗位。用户列表和审批流都会用到部门。
- **字典管理**：下拉框、标签这类固定选项统一定义（比如「客户等级：A/B/C」）。出厂自带的字典受保护，只能改名字不能删。
- **系统设置**：13 个分区——站点信息（名称/Logo/页脚）、登录安全、登录方式、LDAP、单点登录、文件存储、AI 模型、短信、通知渠道、地图服务、语言、参数。带「测试」按钮的分区（短信、邮件、AI 等）填完可以先测再存。多数分区是平台级的：改的是所有租户共用的一份配置。
- **回收站**：误删的用户、公告、角色等先落到这里，可以还原，也可以彻底删除。
- **数据备份**：手动点「立即备份」，或配置定时备份和保留策略；备份文件可以下载。仅超管可用。

## 开发与安全

- **插件管理**：已装插件的总览。每张卡片显示版本和授权状态，有独立的启用/停用开关；可以从插件市场一键安装，pro 插件在这里导入授权文件。部分插件停用/启用后需要重启。
- **定时任务**：配置到点自动执行的任务（5 段 cron）。支持立即执行、失败重试，每次执行都有日志。
- **代码生成器**：挑一张业务表（或在向导里定义一张新表），一键生成后端模块、前端页面和数据库迁移。可以先在线预览，再下载 zip 或直接写入项目。
- **SAML 单点登录**：接入企业 IdP（Okta、Azure AD 等）实现单点登录/登出。导入 IdP 元数据即可开始，支持证书轮换。
- **开放平台**：把本系统的接口开放给下游应用——注册应用、管理 HMAC 密钥、配置 Webhook 订阅事件、查看投递记录和在线接口文档。
- **多语言在线编辑**：在网页上直接改界面文案的翻译，支持草稿、发布和按版本回滚，不用改代码文件。

## 内容管理

- **通知公告**：发公告给全员、指定角色/部门/用户。支持富文本、定时发布、置顶、重要公告登录弹窗、已读统计。
- **文件管理**：租户自己的网盘。分组管理，支持大文件断点续传上传、预览、公开/签名下载链接；受租户存储额度限制。

## 系统监控

- **操作日志**：后台每个写操作都有记录（谁、何时、调了什么接口）。可筛选、导出、按天清理。
- **登录日志**：每次登录尝试（成功/失败/IP/设备）。账号被盗排查从这里看起。
- **在线用户**：当前在线的会话，可以把人强制下线。
- **服务监控**：CPU、内存、磁盘、Go 运行时；「前端错误」页签收前端 JS 报错。每 30 秒采样，保留 7 天。
- **缓存监控**：Redis/Valkey 的内存、命中率、key 数量。
- **接口监控**：最近 30 秒各接口的 QPS、耗时、错误率。
- **发送日志**：短信/邮件/机器人的投递结果和失败原因，收件人脱敏存储。

## 租户管理

- **租户管理**：新建租户（客户公司）、续期、启停、看用量。
- **租户套餐**：定义每档套餐给多少用户/存储/AI 额度、能用哪些菜单。
- **我的租户**：租户管理员看自己公司的套餐、额度、用量，维护企业资料。

## 业务中心

这里的页面来自按需安装的插件，装了哪个显示哪个。

- **证件实名**：身份证号校验、姓名+证件号二要素核验，核验结果留台账。
- **支付中台**：对接支付宝、微信支付等渠道。支付单、退款、对账、代付、结算都在这里，资金动作全部留痕。
- **在线客服**：官网右下角聊天的坐席工作台。访客来消息自动分配或排队，坐席认领后回复；支持转接、快捷回复、内部备注、满意度评价、会话合并和导出。
- **工单中心**：客户问题的提交、分派、处理、关闭全流程。支持优先级、SLA 时限、内部备注、附件和自动化规则。
- **审批中心**：业务流程的审批（如请假、报销）。管理员在 BPMN 画布里画流程，发起后按图流转；支持或签/会签、超时自动升级、撤回与回退。
- **设备监控**：把变频器、PLC 等工业设备接入后台，实时读数、历史曲线、超限告警、远程下发指令。
- **客户主数据**：客户档案、联系人、跟进记录、商机台账；把酒店、商城等外部系统的会员对齐到同一个客户。

## 网站管理

管理企业官网（访客不需要登录就能看的那个站）的内容：

- **产品管理 / 产品类目**：产品的上架、下架、图集、价格与起订量；类目支持多级。配好阿里国际站凭据后可以一键把商品发到阿里。
- **站点设置**：官网的名称、Logo、首页标题、页脚、SEO、隐私政策地址。
- **导航管理**：官网顶部导航条，支持外链和站内页面。
- **特性管理**：官网首页「产品特性」卡片的文案与图标。
- **页面管理 / 新闻管理**：官网的静态页（关于我们等）和新闻，都支持多语言、定时发布和草稿预览。
- **留言管理**：访客从「联系」页提交的留言：未读徽标、三态处理（待跟进/已跟进/已忽略）、批量操作与导出。

## 个人中心

右上角头像 → 个人中心：改自己的资料和密码、绑定手机号/第三方账号、管理登录设备和个人访问令牌（用来调开放接口）。两步验证的绑定也在这里。
